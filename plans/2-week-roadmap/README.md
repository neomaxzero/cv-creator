# 2-Week CV Creator Roadmap

This folder contains a two-week implementation plan designed for iterative execution with an orchestrator.

## Goals

- Refactor the app into maintainable modules without changing user-visible behavior.
- Add durable CV persistence and import/export capabilities.
- Improve quality gates, documentation, and delivery confidence.
- Start type-safe modeling and test coverage for core editing flows.

## Structure

- `week-1-foundation.md` — safe refactor, persistence, and baseline project hygiene.
- `week-2-quality-and-types.md` — TypeScript model migration, tests, and stricter automation.

## Orchestrator Guidance

- Execute tasks in order of priority within each week.
- Treat each checkbox as a potential issue/ticket.
- Keep pull requests small and scoped to one milestone whenever possible.
- Reassess scope at each end-of-week checkpoint before starting the next week.
